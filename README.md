# NSBM StudyCircle – Student Community for Notes and Study Sharing

A web application that lets NSBM students share notes and study materials in one place.

## Module
Web and Mobile Application Development – NSBM Green University

## Features
- Browse and view study materials
- Upload and share notes
- Student community for collaborative learning

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL (phpMyAdmin / XAMPP)

## Project Files
| File | Purpose |
|------|---------|
| `study_materials.html` | Page structure |
| `study_materials.css` | Styling |
| `study_materials.js` | Client-side functionality |
| `study_materials.php` | Server-side logic |

## How to Run
1. Install XAMPP and start Apache and MySQL.
2. Copy the project folder into `htdocs`.
3. Open `http://localhost/<project-folder>/study_materials.html` in your browser.
